# 记录与交付模板

只复制本轮需要的模板并填写。下列空白字段是模板槽位，不代表已经执行。既有项目沿用原编号；新项目可使用本页编号，跨项目引用时带项目标识。

目录：来源 SRC；观察 OBS；完整功能清单 F；行为合同 BEH；用例 TC；关键决策 DEC；运行与差异 RUN/GAP；plan.md 日志与接续点。

## 1. 来源 SRC

```markdown
## SRC-001 / 来源名称
- 类型：O 目标实测 / U 用户报告 / S 截图 / W 网页 / H 假设 / D 自主设计
- 网址或本地路径：
- 提供/访问日期：
- 产品版本、平台、语言、账号/档位：已知值；未知明确填写未知
- 具体支持的功能/陈述：
- 局限、内容变动或冲突：
```

网页没有版本号时不把访问日期当成产品版本；用户截图的提供日期也不是拍摄日期。

## 3. 全量清单与覆盖矩阵 F

先登记完整候选清单，再让用户确认本轮范围；粗粒度组下拆出可检验的子行为，避免一个巨大功能组掩盖未完成项目。

```markdown
| ID | 功能/子行为 | 来源与证据类型 | 依赖 | 本轮范围 | BEH/TC | 实现状态 | 验收状态 | 结果证据/差异 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| F-001 | | | | 待确认 | | 未开始 | 未执行 | |
```

- 范围：纳入 / 待确认 / 延期 / 明确排除；延期、排除须写原因和用户决定，保留原行。
- 实现：未开始 / 部分实现 / 已实现；对无需实现的排除项用不适用。
- 验收：未执行 / 通过 / 失败 / 阻塞；不适用项解释原因，不混入通过数。
- 原产品档位另作来源备注；不能自动成为本产品的付费墙或范围排除。
- 汇总同时给候选总数、纳入数、延期/排除/待确认数。实现比例与验收比例分别计算并写清分母；不把被阻塞的项目静默移出范围。

## 4. 行为合同 BEH

```markdown
## BEH-001 / 行为名称
- 关联 F、OBS、SRC：
- 依据：目标实测 / 用户报告 / 网页/截图线索 / 采用的自主设计
- 前置条件与触发入口：
- 输入与合法范围：
- 正常操作与可见结果：
- 状态转移、数据变化与持久化：
- UI 约束、焦点/选择与禁用条件：
- 错误条件、提示及恢复：
- 边界、取消、并发/资源冲突：
- 依赖与跨功能影响：

- 验收用例 TC：
```

提示文字要区分“目标实际原文”和“本产品拟采用文案”。自主设计的细节使用本产品合同，不伪造目标行为。

- 环境、数据、设备与前置状态：

同一 TC 可分别在两产品上运行；各自结果独立。只能执行替代实现时，写明目标基线未复测。

## 8. plan.md 节点日志与接续

```markdown
### 日期 / 本次范围
- 当前阶段、目标版本、规格修订：
- 用户已确认的范围/形态/技术栈/安装范围：
- 新增事实、假设或自主设计及文档索引：

- 规格缺口、人工介入次数、修复成本：按实际记录，不用零代替未知
- 当前应用/任务是否运行，是否正在录制/保存/导出：
- 已创建交付物、分支/提交（如有）：

```

日志追加而不覆盖历史；被后续决定取代时注明关联。接续先读最近节点，避免重复安装、重复发布、打断运行中的会话或遗忘待验证项。
